# 员工说明
加入工作群后，有效普通成员由机器人实时核实并自动登记；现有员工无需重新申请。身份按 Telegram 数字账号，姓名与用户名仅展示。遇到成员核验暂时失败请重试；人工停用需联系管理员。

## 工作进度
在最新查询消息点“填写进度”，自动显示本人身份。顺序任务累计选择前置步骤；自由任务可独立选择。每项同页填写“当前问题（选填）”，没有可留空。点击一次“提交反馈”，后台保存成功才显示“已提交”。全部不勾选表示已反馈0项，不提交是未反馈。

提交后本轮只读，已完成阶段不能撤销。新轮仍需再次提交，旧阶段保持锁定，可增加未完成阶段；当前问题新轮留空，历史原文保留。保存失败保留输入，可用同一页面重试，不重复计数。旧查询不能覆盖新轮，从最新群入口重开。不另私聊填写问题，不在群里逐项回执。

## 每日日报（保持现行流程）
在每日报表话题点“日报模板”，或发“日报模板 日期”。填写业务日期及新增、维聊、有效、精聊四个非负整数，备注可选且支持多行。发送即提交，原消息👍代表已记录，无法添加时仅回复“已记录”；无需点击确认。

漏报按原业务日期补发，不改成发送当天。同日完整重发替换数字及备注；不写备注则清空，重复相同内容不累加。0有效，空白会提示补齐。上海时间23:00–次日00:00为正常窗口，窗口外仍可补交。日报和工作进度互不影响。

当前为验收试用，不计正式数据。
