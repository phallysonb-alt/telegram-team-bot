# 管理员总表：三色阶段与问题历史

使用入口保持不变。管理员从查询消息“查看总表”进入，选择任务及历史查询。员工反馈和锁定流程不变。

进度条：实心灰为此前已确认完成；蓝色为所选轮新确认完成；浅灰为截至该轮尚未完成。累计数字、本轮反馈、全部完成、分页和具体步骤保留。展开具体步骤分别列出历史完成、本轮新增、未完成；旧记录无法可靠确定新增轮次时，已确认完成段用灰色并明确标为“完成轮次未确认”，不会编造蓝色新增。

问题区先显示“历史问题”，再显示“本轮问题”。每条保留提交时的账号名称/用户名、任务、轮次、查询和提交时间、当轮进度及完整原文；数字user_id在后台关联，不按姓名合并。历史问题表示曾经反馈，不表示当前仍未解决。未反馈者旧问题仍在；没有本轮问题时显示“本轮暂无新增问题”。

问题每页5条，有独立分页，不按当前人员页隐藏历史；较长原文可展开完整内容。切换任务或查询只显示对应任务、不晚于所选轮的问题，不引用未来问题。旧全局问题缺少可靠任务关联时不猜测归入某任务；旧反馈时间晚于所选查询或时间未确认时会提示，不把它当作当时的历史。原记录始终保留。

后台复用pg_feedback、pg_feedback_delta、任务/名单快照及pg_task_notes，批量读取、分页投影，不创建第二份业务数据源。权限和Telegram签名验证不变。只修改管理员总表投影、展示和相应测试；日报、两类Excel、人员登记、永久锁定、群消息模板及员工提交保持不变。

无需数据库迁移。原单实例stop/start脚本仍负责受控重启；trial验收和正式调度关闭保持。回退恢复本轮备份的progress_miniapp.py、miniapp/app.js、miniapp/style.css，部署原站点v17并重启唯一实例；新只读projection模块可以保留，不影响旧版。禁止用旧数据库备份覆盖当前记录。

集中验收：看第一轮蓝蓝浅灰浅灰，第二轮灰灰蓝浅灰，第三轮未反馈但灰灰灰浅灰；再回看第二轮仍有蓝色第三步。核对历史问题在前、本轮问题在后，旧轮不显示后续问题。独立模拟数据与真实员工记录严格区分，30人模拟不代表30人真实并发。
