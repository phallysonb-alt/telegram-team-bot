# 数据初始化与离线迁移工具

新公司的空库由现有程序按本公司DATA_DIR初始化；scripts/migrate-progress.py保留兼容增表逻辑。没有现有业务的独立公司不需要恢复其他公司的私有备份。两套Excel仅从各公司自己的业务库生成，templates是已审核的格式参考，不导入模板示例到业务库。

已有同一公司搬电脑时，migration/create_private_snapshot.py制作私有快照，restore_private.py inspect只读核验，restore仅允许新目录并需明确--old-pc-stopped。所有密钥、配置、数据库和业务文件仍在私有备份，禁止提交。test_migration_tools.py使用独立模拟数据验证拒绝覆盖、损坏、越界、运行锁及兼容路径调整。

本仓库沿用当前实际运行版本的Windows启动脚本，本次Git托管不改变它们。此前专门的新电脑迁移ZIP带有额外的启动保护；本仓库标准start.cmd不会读取HANDOVER_PENDING。恢复工具写出的HANDOVER_PENDING仅表示待操作员核验，activate.py只记录操作者确认，不能代替核实旧机已停止。实际停止、恢复、切换仍需用户单独授权，不因本次GitHub授权自动执行。

其他公司的凭据、群、人员和数据必须独立。同一个Bot Token不能跨两台电脑同时polling。代码更新不等于业务数据迁移，也不等于启用正式调度。
