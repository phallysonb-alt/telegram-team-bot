# 管理员说明
业务管理员由本地明确配置，群管理员身份不会自动授权。管理群保持人工沟通。

## 发布和查询
进度话题置顶“发布任务”打开 Mini App，同页填任务主题、默认3步、可加第4步，选择按顺序或自由完成。＋任务追加，发布任务一次保存，成功清空草稿，群里逐任务展示完整阶段。已使用任务结构锁定，另发布独立任务；示例不是正式业务标准。

发送“查询任务”，查询当日全部有效任务；每次底部有新的持久入口，后台冻结当时任务与人员范围。无定时查询。查看总表按任务切换、10人分页，具体步骤可展开。姓名和用户名分列，当前问题单独显示，历史下拉查看各轮。提交后只编辑原群消息的反馈人数，不新增每人汇总。

已提交阶段永久累计锁定，同轮只读。新轮需再次提交，不能沿用上轮已反馈状态；问题原文逐轮保留。

## 人员
普通有效群成员自动登记，共用日报与进度名单，纯管理账号和机器人不计业务员。入群申请由 Telegram 群主处理，不需第二次 Mini App 审批。已有四名员工不重新登记。管理员私聊“员工管理”保留停用、恢复及排查能力；恢复前实时核实普通群成员身份。人工停用不会自动解除。历史名单不被新增员工改写。

## 导出和日报
管理员私聊发送“导出跟进表”，获取独立工作进度历史.xlsx四张表。文件占用时关闭后重试，后台也会补写；不下载旧版本冒充最新。

日报冻结：查看日报 日期 [页码] 每次在底部给最新数据；之后修订编辑最新一张。导出日报表下载日报历史记录.xlsx，进度永不覆盖它。请假、停用和日报纠错继续使用现有管理员私聊权限，具体既有命令见帮助。正式调度关闭，不自行启用。
