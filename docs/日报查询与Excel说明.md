# 日报简明使用说明

员工在“每日报表”发送业务日期、四项非负整数和可选多行备注，保存后原消息出现👍；表情无法使用时回复“已记录”。不弹预览，不需确认，不主动新增团队表。漏报保留原日期补交；同日完整重发替换，不累加；未写备注表示清空备注。

管理员发送“查看日报 2026-10-11”，每次明确查询均在聊天底部回复最新数据，并回复对应查询消息。翻页按钮更新当前表；补交或修订只更新该日期最新一张查询表，没有查询表时只同步数据库和Excel。

管理员私聊“导出日报表”下载数据库最新版本。固定文件为exports/日报历史记录.xlsx。占用或同步失败时保留待更新，不将旧文件当成最新导出。

Excel业务日期采用数值日期，显示YYYY-MM-DD，不进行本地时区偏移。每日汇总固定表头；员工明细只固定两行标题，日期分区随正文滚动。

当前为独立验收，正式调度关闭。正常窗口23:00–次日00:00，00:05安排不变。英文入口兼容。身份始终按数字user_id，显示Telegram账号资料名称及用户名。

日报姓名展示：群内与固定Excel的员工明细均为员工名称、Telegram 用户名、新增、维聊、有效、精聊，备注/状态在Excel后续列。用户名缺失显示—；绑定仍使用数字user_id。姓名与用户名数据左对齐，表头及指标居中，长名称换行显示，原数字、备注、历史不改变。
