# Excel 导出入口

管理员私聊机器人发送下列普通中文文字，或在“工作菜单”点击同名按钮：

- **导出日报表**：发送原 `exports/日报历史记录.xlsx`，两个工作表：每日汇总、员工明细。
- **导出跟进表**：发送原 `exports/工作进度历史.xlsx`，保持 V2 四工作表：查询汇总、员工进度历史、当前问题历史、任务定义。

先更新至数据库当前版本，再通过原有发件队列发送；文件占用或网络失败仍保留既有重试机制。两者路径、数据源及发送处理独立。

旧文字“导出历史报表”“导出日报历史”“导出进度历史”“导出工作进度历史”继续兼容。原按钮回调 `daily_export`、`pg:export` 不变，原英文 `/daily_export` 继续可用，不设置中文斜杠命令。旧 `/export` 为既有 CSV/JSON/Markdown 功能，未改为 Excel。

本次仅统一入口、按钮、帮助及文件说明名称，不修改数据库结构、业务记录、日报流程、Excel 生成程序或版式。普通员工无导出权限。保持独立验收、正式调度关闭。

本轮验证：新增7项处理入口测试通过，涵盖中文/英文/旧词/按钮、管理员权限、同一更新去重、失败重试、独立路径及真实生成的2/4工作表。另有原进度13项回归通过。真实已登录管理员在 Telegram Desktop 点击两个新按钮并分别发送两个新中文词，均收到对应 Excel；原始发送队列显示 sent，跟进发送接口为 sendDocument。未要求员工提交或修改已有记录。
