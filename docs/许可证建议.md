## 第三方边界

Python 依赖由 `requirements.lock.txt` 锁定，云端工具由 `deploy/package-lock.json` 锁定。它们保留各自许可证；不能用本项目 MIT 声明替换。当前安装包元数据中，python-telegram-bot 22.8 为 LGPL-3.0-only，openpyxl 3.1.5 为 MIT，cryptography 50.0.2 为 Apache-2.0 OR BSD-3-Clause，httpx 0.28.1 为 BSD-3-Clause。此处不是全依赖许可清单，分发带依赖的二进制包前仍应复核每个相应版本的 LICENSE/NOTICE；本仓库仅引用依赖、不打包第三方运行文件。

仓库不包含第三方运行环境、node_modules、虚拟环境或 `@oai/artifact-tool` 软件包。`scripts/package.json` 中该包是可选开发环境声明，不能据此声称获得再分发权或要求公开下载专有包。普通部署使用项目已支持的 openpyxl 兼容路径；Codex/ChatGPT 账户不是部署前提。

Excel 模板目前仅作为经过摘要审核的格式参考/模拟模板分发，不含业务库。其原始设计权利也须由提供方确认。后续改模板必须重新检查数据、元数据与授权，不能只因为文件名含“模板”就放行。
