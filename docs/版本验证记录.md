# 版本验证记录

仓库保存可部署程序、通用模板及有效测试。公司实际账号、业务数据、截图、完整聊天日志、运行配置与现场验证文件只留本地，不进入Git历史。

每次开发收尾由同步脚本实际运行相关检查；Git提交正文的 `Validation-Tree` 与 `Validation-Checks` 对应当次准确版本。运行原始证据在该克隆的 `.git/sync-test-logs`，未执行的真实客户端验收不能据自动测试宣称通过。

当前Git托管改动仅限源码管理、保密规则、提交/推送工具与通用部署依赖文件；不修改既有业务规则，不重启机器人，不重新部署线上服务。临时仓库中的断网/冲突测试使用本地裸仓库，不属于真实GitHub或员工业务操作。

其他公司的部署必须使用独立凭据、群、数据库及数据目录。模板中的格式参考/模拟数据不代表当前公司的实际记录，不导入业务库。
