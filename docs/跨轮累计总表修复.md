# 管理员总表：本轮反馈与累计进度

工作进度的总表现在分开显示本轮是否提交和截至所选查询的累计完成阶段。员工本轮未反馈时，仍保留以前确认的蓝色进度条；此前全部完成标为“未反馈｜历史已完成3/3”，部分完成标为“未反馈｜历史累计2/3”，没有任何记录标为“未反馈｜暂无记录”。明确提交0阶段与没有记录不同。

顶部“本轮已反馈”只计所选轮的本人提交。“累计全部完成”按当前选中的任务计数，分母都是本轮冻结的应反馈名单。历史已完成者不会被自动算成本轮反馈。

使用方式不变：管理员从群内“查看总表”打开；切换任务、翻页、刷新及查询历史沿用原按钮。展开“具体步骤”可查看截至该轮已完成阶段；具备既有增量记录的本轮反馈同时显示“本轮新增”，无新增阶段也会明确显示。旧反馈没有可靠增量记录时不编造新增。

旧问题仍归所属轮次。历史查询只读取不晚于该轮的已确认反馈，按task_id、任务版本及数字user_id关联，不使用同名任务推算，也不使用全局最新锁定值覆盖早期历史。新增员工不会进入旧轮名单。

本轮无数据库结构迁移。只修改管理员总表API投影和前端展示；日报、两类Excel、员工提交与永久锁定、人员登记、群消息模板及部署结构保持不变。重启采用原stop/start脚本，保留待处理更新。回退仅恢复修改前的progress_miniapp.py和miniapp/app.js，部署上一站点版本并重启原实例；不得用旧备份覆盖当前业务数据库。
