# 工作填报口径
精聊是符合团队有效客户标准并完成当阶段沟通的客户数。标准应由管理员另行明确，系统不会自行判断有效性。
引流是从社交平台转入指定沟通软件的客户数。机器人只记录员工自行填报，不执行引流。
维聊是当日完成维护沟通的在聊客户数。
# 阶段与日报
上半场与下半场均填写本阶段新增量，不填累计值。全天合计等于两个阶段相加。
没有完成的工作请明确填零，尚未核实的数据留空，留空显示待补。
最终日报确认后覆盖阶段数据，不与阶段数据重复相加。
# 多人任务
每位负责人分别更新状态。只有全部负责人完成时，任务才能算全部完成。
# 资料与隐私
默认资料仅在本地检索。机密资料不得标记为允许外发，不能在问答里填写客户姓名、电话、钱包或个人身份资料。
